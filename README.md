# Calendário Acadêmico 📅

Aplicação web para visualização e organização de calendário acadêmico. Desenvolvida com HTML, CSS e JavaScript.

## 📋 Sobre

Ferramenta que permite visualizar datas importantes do calendário acadêmico de forma organizada e intuitiva — provas, prazos, eventos e feriados em um só lugar.

## 🛠️ Tecnologias

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## ✨ Funcionalidades

- Visualização do calendário por mês
- Marcação de datas importantes
- Interface responsiva e amigável

## 🚀 Como rodar

```bash
# Clone o repositório
git clone https://github.com/michellepichau/calendarioacademico.git

# Abra o index.html no navegador
# Ou use Live Server no VS Code
```

## 📚 Conceitos praticados

- Manipulação do DOM com JavaScript
- Renderização dinâmica de calendário
- Estilização responsiva com CSS Grid
